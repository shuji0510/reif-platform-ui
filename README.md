# reif-platform-ui
REIF 食のクローズドマッチングプラットフォーム UI モックアップ

## english-island-quest/
中学1年英語（教科書 Unit 0〜5 の文法事項）を島めぐり形式で学ぶブラウザゲーム。`english-island-quest/index.html` をブラウザで開けば動く（ビルド不要・外部依存は Google Fonts のみ）。

ホーム画面に追加できるWebアプリ（manifest・オフライン用 service worker・アイコン）として作ってあり、アプリ内の「友だちに教える」からQRコードとリンクを配れる。

公開手順（GitHub Pages）: リポジトリの Settings → Pages → Source を「Deploy from a branch」、ブランチをこのゲームが入っているブランチ、フォルダを `/ (root)` にして Save。数分後に https://shuji0510.github.io/reif-platform-ui/english-island-quest/ で公開される。

## hikari-kage-museum/
中学1年美術の鑑賞（教科書 P.110〜113「レオナルド・ダ・ヴィンチ」「レオナルドの手稿」「明暗のドラマ」）で、教科書にのっている名画19点を、絵と題名で覚えるブラウザゲーム「光とかげの美術館」。`hikari-kage-museum/index.html` をブラウザで開けば動く（ビルド不要）。

- 覚える: 作品図鑑（題名をかくして自分でためせる）、フラッシュカード
- 練習する: 絵を見て題名、題名から絵を選ぶ、ぼかしあて、ズーム、神経衰弱、ヒントクイズ、作者・美術館・年代、ならべかえ
- 体験する: 技法ラボ、光のラボ、学芸員試験
- PWA対応（ホーム画面に追加、オフライン可）、QRコード共有つき

### 画像について
`img/` の画像（`img/s/` は縮小版）は、教科書 P.110〜113 の写真から切り出したものです。作品はいずれも作者の没後70年以上たったものですが、教科書の図版そのものを不特定多数に公開する場合は、出版社の扱いを確認してください。広く公開する前に、ウィキメディア・コモンズなどのパブリックドメイン画像に、同じファイル名（`img/<id>.jpg`、`img/s/<id>.jpg`）で差しかえられます。
